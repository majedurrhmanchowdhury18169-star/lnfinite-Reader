# Infinite Reader (100% Offline & Ad-Free)

ফোন দিয়ে GitHub-এ **APK** তৈরি করার সহজ ধাপ:

1. GitHub-এ একটি নতুন Repository তৈরি করুন (যেমন: `infinite-reader`)।
2. এই ZIP ফাইলটি আনজিপ করে সব ফাইল (`.github` ফোল্ডারসহ) ওই Repository-তে আপলোড করুন।
3. Repository-র **Actions** ট্যাবে যান এবং **Build Infinite Reader APK** ওয়ার্কফ্লো রান করুন (অটোমেটিকও শুরু হবে)।
4. বিল্ড শেষ হলে (প্রায় ২-৩ মিনিট) নিচে **Artifacts** সেকশন থেকে `Infinite-Reader-Offline-APK` ডাউনলোড করে আনজিপ করুন এবং ফোনে ইনস্টল করুন।

**বিঃদ্রঃ** বিল্ডের সময় GitHub Actions স্বয়ংক্রিয়ভাবে সব লাইব্রেরি অফলাইনে বান্ডেল করে নেবে, তাই ইনস্টল করার পর অ্যাপটি সম্পূর্ণ **ইন্টারনেট ও অ্যাড ছাড়াই** চলবে।
